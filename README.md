# Nogoom Sports Bot\n\nTelegram bot for weekly/monthly subscriptions, Vodafone Cash receipt review, admin approval, subscription status, and automatic channel-post reactions.\n\n## Railway variables\n\n- `BOT_TOKEN` (required; create a fresh token with BotFather and add it privately in Railway)\n- `ADMIN_ID` (defaults to `6809336258`)\n- `PAYMENT_NUMBER` (defaults to `01024689530`)\n- `WEEKLY_PRICE` (defaults to `200`)\n- `MONTHLY_PRICE` (defaults to `500`)\n- `CHANNEL_ID` (optional; restricts reactions to one channel)\n\nAdd the bot as a channel administrator with permission to change channel messages/reactions. Railway should run the `worker` process from the Procfile.\n
